# 虚拟资本论 · AI 股东交易场

**手机/公网网址：** https://clan-glitch.github.io/virtual-capital-arena/

这是一个可在手机和桌面浏览器使用的静态模拟交易游戏。打开上方网址后，可通过浏览器菜单将它添加到主屏幕。

## 功能

- 虚拟股票与 AI 股东竞赛
- 每 24 小时自动结算模拟日；重新打开页面时补齐已错过的结算
- Binance、Bybit 实际挂牌的加密现货与 USDT 永续目录及公开 K 线（只读）
- 1 分钟至 1 年 K 线周期，周期偏好保存在本机；主图 SMA / EMA / 布林带、副图成交量 / RSI / MACD
- K 线 OHLC、时间、涨跌和振幅悬浮提示，实时成交量/成交额及公开订单簿深度快照
- 100+ 个虚拟股票代码、190 个外汇交叉盘选择项
- 现货及永续合约的本地模拟订单
- 1–1000 倍模拟杠杆、两档高难度设置、每 8 小时模拟资金费率结算及随机爆仓提示
- ECB 日基准外汇参考数据（非实时盘口）、虚拟杠杆与 50% 模拟借贷年化率
- 10,000 个模拟席位的本地竞赛榜
- PWA 主屏幕安装与离线应用外壳

## 数据与安全说明

所有账户余额、股票价格、交易订单、借贷、资金费率和排行榜对手均为本地模拟，不是真实金融服务。加密品种目录、K 线和订单簿只从所选交易所公开只读接口读取；接口不可用时不会伪造盘口，图表会明确回退为演示价格。K 线支持 1 分钟至 1 年，1 年周期由公开月线汇总。成交额使用成交量乘以收盘价估算。永续合约的费率与 8 小时结算是练习机制，参考 [OKX 公开说明](https://www.okx.com/help/iv-introduction-to-perpetual-swap-funding-fee)，不复刻其实时费率、风控或结算服务。外汇使用可用的最新 ECB 日参考汇率，缺少参考值时显示模拟报价。网页不收集交易所账户信息、不提交真实订单、不提供真实杠杆或借贷，也不构成投资建议。

24 小时自动结算依赖浏览器本地存储；浏览器暂停后台计时器时，会在下一次打开页面时补结算。
