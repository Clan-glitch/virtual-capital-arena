# 虚拟资本论 · AI 股东交易场

**手机/公网网址：** https://clan-glitch.github.io/virtual-capital-arena/

这是一个可在手机和桌面浏览器使用的静态模拟交易游戏。打开上方网址后，可通过浏览器菜单将它添加到主屏幕。

## 功能

- 虚拟股票与 AI 股东竞赛
- Binance、Bybit 公开加密货币 K 线（只读）
- 现货及永续合约的本地模拟订单
- 演示外汇、虚拟杠杆与模拟借贷
- 10,000 个模拟席位的本地竞赛榜
- PWA 主屏幕安装与离线应用外壳

## 数据与安全说明

所有账户余额、交易订单、借贷、排行榜对手和外汇报价均为本地模拟，不是真实金融服务。公开加密货币行情只读连接交易所。此项目不收集真实用户账户信息、不提交交易、不提供真实借贷或投资建议。
